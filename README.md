# Avatar Workflow

If you want an assistant to make avatar videos for you, heygen mcp is the search you land on. The generation step is the easy half.

**Read the full page:** https://heygen-mcp.github.io/

HeyGen is the serious option for talking-head avatar video, and its own homepage carries a developers section, so a programmatic path exists for people who go and read the documentation. What the front page does not do is describe a Model Context Protocol server, so verify that specifically rather than trusting a blog post. The caveat that catches everyone: generation gives you a raw clip, and a publishable video still needs trimming, cropping to the right aspect ratio and burned-in captions. I do that part in Vidione because it runs in a browser with nothing to install, which keeps the last mile from becoming its own project.
